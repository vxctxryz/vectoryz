OSS·FLOSS·

vectoryz nutzt freie und offene Software. Diese Übersicht ist keine vollständige Stückliste und ersetzt keine Lizenzdokumentation; sie nennt die wichtigsten technischen Säulen. Danke an alle Entwickler:innen und Beitragenden.

Engine-Layer

llama.cpp Inference-Engine für lokale LLMs. MIT
Ollama Model-Daemon und Pull-Mechanik zum Laden und Ausführen lokaler Modelle. Lizenzangabe bezieht sich auf das Ollama-Repository, nicht auf geladene Modelle. MIT

Webserver / Routing

Caddy Reverse-Proxy und Static-Server mit automatischem HTTPS. Apache-2.0

Wrapper / Server-Logik

Python Standard Library Der vectoryz-Wrapper nutzt die Python-Standardbibliothek, u. a. http.server, urllib, sqlite3, json und re. PSF
ddgs Suchadapter für den Faktencheck-Workflow. MIT

Frontend

WebCrypto / SubtleCrypto Browser-seitige Kryptografie auf Basis der Web Crypto API. Schlüsselmaterial wird nicht als Query-Parameter übertragen, sondern im URL-Fragment gehalten. Keine zusätzliche Library. Web-Standard
HTML / CSS / JavaScript Kein Framework, kein Build-Step. Die Oberfläche ist als eigenständige HTML/CSS/JS-Datei nachvollziehbar. —

Datenquellen

DuckDuckGo Privacy-orientierte Websuche; genutzt als externe Suchquelle. —
Wayback Machine / Internet Archive Historische Snapshots — hilfreich für Quellenkontext, Recherchestand und Begriffsgeschichte. —
sources.yaml Kuratierte Primär- und Referenzquellen, u. a. Bundesbehörden, EU-Institutionen und Standards-Bodies; mit transparentem Quellen-Tiering. CC0 / operator-kuratiert
