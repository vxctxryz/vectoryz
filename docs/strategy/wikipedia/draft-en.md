'''vectoryz''' is an open-source software system for generating and checking AI-assisted answers. The project was developed by Nuremberg-based IT specialist Benjamin Resch and entered an early access phase in May 2026.

== Concept ==
vectoryz combines locally hosted open-source language models with a wrapper designed to check generated answers at the level of individual claims. Claims are classified using reliability tiers including ''factfact'', ''quasifact'', ''maybefact'', ''quasinonfact'' and ''nullfact''.

The system includes an optional multi-witness procedure intended to compare claims with multiple sources. A phase timeline documents processing stages such as classification, search, generation and verification.

== Privacy ==
According to the project documentation, vectoryz is designed without cookies or tracking. Chat contents are encrypted client-side with AES-256-GCM; the key remains in the user's browser. Server logs and chat data are scheduled for automatic deletion after seven days.

== Development ==
The source code and project documentation are released under the MIT Licence. Known issues and design decisions are documented publicly by the project.
